# CamCue 탈리 램프 — M5StickC Plus

M5StickC Plus 를 카메라 위 **탈리 램프**로 씁니다. 캠큐 PC 에서 내 카메라 상태만 받아 화면 전체를 탈리 색으로 보여 줍니다.
스위처에 직접 붙지 않고 캠큐를 거치므로 **이케가미(랜 탈리)·ATEM·vMix·OBS·GPI 탈리 모두** 같은 방법으로 씁니다.
ATEM 이라도 램프 수만큼 ATEM 접속 자리를 쓰지 않습니다(캠큐 1자리만 사용).

> ⚠️ 이 펌웨어는 **컴파일까지만 확인**했고 M5StickC Plus 실물로는 아직 시험하지 않았습니다. 첫 사용은 예배·행사가 없는 시간에 확인해 주세요.
> M5StickC Plus**2** 는 대상이 아닙니다(전원·LED 구조가 다름).

## 화면

| 화면 | 뜻 |
|---|---|
| **빨강** + `ON AIR` (+ 본체 빨간 LED) | 내 카메라 송출 중. 아래 작게 지금 샷(MS 등) |
| **초록** + `PVW` | 다음 송출 대기(PVW). ATEM · vMix · OBS 만 (이케가미 랜 탈리는 PVW 를 못 읽음) |
| 어두운 화면 | 대기. `다음 내 샷` 아래 크게 `MS` · `바로 다음`/`3큐 뒤` · 맨 아래 `송출: CAM 2` / `송출: PPT` |
| `추정` 표시 | 스위처 실제 신호가 아니라 큐 진행 기준 (스위처 연결 끊김 등) |
| `리허설` 표시 | 캠큐 리허설 모드 |
| 노란 글씨 `연결 끊김` 등 | 캠큐와 연결이 안 됨. **이때는 빨강을 표시하지 않습니다** (옛 탈리를 남기지 않음) |

연결이 끊기면 10초 안에 `연결 끊김` 으로 바뀌고 자동으로 다시 붙습니다.

## 버튼

| 버튼 | 동작 |
|---|---|
| **A** (앞면 큰 버튼, M5 글자) | 카메라 번호 바꾸기 1 → 2 → … → 8 → 1 (저장됨) |
| **B** (오른쪽 옆면) | 화면 위아래 뒤집기 (거치 방향에 맞춰) |
| **B 2초** | 설정 모드 (와이파이 다시 설정) |
| 전원 (왼쪽 옆면) | 2초 누르면 켜짐 · 6초 누르면 꺼짐 |

## 1. 펌웨어 올리기 (처음 한 번)

준비물: M5StickC Plus, USB-C 케이블(데이터 되는 것), Windows PC 의 **크롬 또는 엣지**.

1. 펌웨어 파일 **`camcue-tally-m5stickc-plus.bin`** 을 받습니다.
   - CamCue Releases 페이지의 첨부 파일, 또는 GitHub Actions "탈리 램프 펌웨어" 실행 결과의 아티팩트(zip 안에 있음)
2. 크롬에서 **https://espressif.github.io/esptool-js/** 를 엽니다 (Espressif 공식 웹 플래셔).
3. M5StickC Plus 를 USB 로 PC 에 연결 → **Connect** → 목록에서 포트 선택
   - 포트가 안 보이면 USB 드라이버가 필요합니다. M5Stack 공식 문서(StickC Plus → USB Driver)에서 받아 설치하세요.
4. **Flash Address 를 `0x0`** 으로 바꾸고 파일 선택 → **Program**
5. 끝나면 본체가 다시 시작하며 **설정 모드** 화면이 뜹니다.

## 2. 처음 설정 (폰으로)

1. 본체 화면의 와이파이 이름 **`CamCue-Tally-XXXX`** 에 폰으로 연결합니다 (비밀번호 **`camcue1234`**, 본체 화면에도 표시).
2. "Wi-Fi 네트워크에 로그인" 알림이나 설정 화면이 뜹니다. 안 뜨면 **크롬·웨일** 주소창에 **`http://4.3.2.1`**
   - 주소가 192.168.x.x 가 아니라 4.3.2.1 인 이유: 갤럭시는 공인 IP 모양 주소에서만 "로그인 필요" 화면을 띄웁니다 (WLED 등도 같은 주소 사용)
3. 입력하고 **저장하고 다시 시작**
   - **와이파이**: 캠큐 PC·카메라맨 폰이 쓰는 **같은 공유기** (2.4GHz 만 됩니다)
   - **카메라 번호**: 이 램프를 올릴 카메라
   - **캠큐 PC 주소**: 비워 두면 자동으로 찾습니다. 못 찾을 때만 캠큐 창에 표시된 IP 입력 (예: `192.168.0.10:38080`)
4. 본체가 다시 시작해 `캠큐 찾는 중` → 대기 화면이 되면 완료입니다.

나중에 와이파이를 바꾸려면 **B 를 2초** 눌러 설정 모드로 들어갑니다. 저장하지 않고 나가려면 A.

## 문제 해결

| 증상 | 확인 |
|---|---|
| 폰에서 설정 화면이 안 뜸 | 설정 모드 화면 오른쪽 위를 보세요. `폰 대기` = 폰이 아직 안 붙음, `폰 연결됨` = 붙었는데 화면을 못 받음, `화면 열림` = 정상. 알림창의 "Wi-Fi 네트워크에 로그인" 을 누르거나, **삼성 인터넷 말고 크롬·웨일**로 `http://4.3.2.1` (삼성 인터넷에서는 안 열리는 사례 확인). 그래도 안 되면 모바일 데이터를 잠깐 끄기 |
| `와이파이 연결 중` 에서 멈춤 | 공유기 이름·비밀번호, **2.4GHz** 인지 (5GHz 전용 공유기는 안 됨) |
| `캠큐 찾는 중` 에서 멈춤 | 캠큐 PC 와 **같은 공유기**인지. 캠큐가 켜져 있는지. Windows 방화벽이 캠큐(UDP 38089, TCP 38080)를 막지 않는지. 안 되면 설정 모드에서 캠큐 PC 주소를 직접 입력 |
| `캠큐 업데이트 0.1.1 이상 필요` | 캠큐 PC 프로그램이 이 기능이 없는 옛 버전 |
| `연결 불가 · 캠큐 HTTPS 모드` | 캠큐를 HTTPS(TLS_CERT)로 실행 중. 이 램프는 HTTP 만 지원 |
| 배터리가 금방 닳음 | 내장 배터리는 120mAh 로 작습니다. 와이파이·화면을 계속 켜 두므로 **USB 보조배터리 연결 권장** |

진행 기록은 USB 로 볼 수 있습니다: esptool-js 의 **Console** → Connect(115200) → Start. `[setup]` `[wifi]` `[find]` `[tally]` 줄이 찍힙니다.

## 캠큐 쪽 통로 (직접 만드는 기기용)

| 주소 | 내용 |
|---|---|
| `GET /api/tally?cam=N` | 지금 상태 한 번 (JSON) |
| `GET /api/tally/stream?cam=N` | 바뀔 때마다 `data: v=1&cam=1&st=pgm&real=1&rh=0&shot=MS&next=WS&in=3&now=` 한 줄 (text/event-stream, 4초마다 `: ka` 확인 줄) |

`st` = `pgm`(송출) / `pvw` / `off`, `real` = 실제 탈리 여부, `in` = 다음 내 큐까지 남은 큐 수(-1 = 없음), `now` = 지금 송출 중인 다른 것.
HTTP/1.0 으로 요청하면 chunked 없이 줄 단위로 그대로 옵니다.

## 직접 빌드 (Arduino IDE)

- 보드 매니저: **esp32 by Espressif** (배포판은 2.0.17 로 빌드) · 보드 **M5Stick-C** (최신 코어에서는 M5StickC Plus 항목)
- Partition Scheme: **Minimal SPIFFS (1.9MB APP with OTA)** — 한글 글꼴 때문에 기본(1.2MB)으로는 모자랄 수 있습니다
- 라이브러리: **M5Unified** (M5GFX 가 함께 설치됨). 배포판은 M5Unified 0.2.9 · M5GFX 0.2.14
- 저장소의 GitHub Actions(`.github/workflows/firmware.yml`)가 같은 방법으로 빌드합니다
